# 🚀 AmneziaWG Cascade v3 — режимы развёртывания, дополнительные протоколы, Web-панель

> **v3 — отдельная ветка развития проекта.** Стабильная каскадная версия v2 остаётся в репозитории [amneziawg-cascade-v2](https://github.com/daff4ik/amneziawg-cascade-v2) без изменений.

Готовое решение для развёртывания VPN на AmneziaWG 3.1 с обфускацией: на одном сервере, на двух серверах каскадом или с разделением «панель здесь — протоколы там». Плюс дополнительные протоколы (VLESS+REALITY, MTProxy, сайт в Tor), устанавливаемые в один клик из веб-панели.

## 🆕 Что нового в v3

*   **Три режима установки** (выбирается первым вопросом установщика):
    *   **Режим 1 — только SERVER-A:** протоколы и веб-панель на одном сервере. Второй сервер не нужен.
    *   **Режим 2 — только SERVER-B:** протоколы и клиенты живут на втором сервере, веб-панель и управление — на SERVER-A (панель управляет B по SSH-ключу).
    *   **Режим 3 — каскад A+B** (как v2): клиенты → SERVER-A → туннель → SERVER-B → интернет.
*   **Вкладка «🧩 Протоколы» в веб-панели:** установка и удаление дополнительных протоколов/сервисов в один клик:
    *   **VLESS + REALITY (Xray)** — ссылка `vless://` для импорта в AmneziaVPN и другие клиенты;
    *   **MTProxy (Telegram)** на базе mtg v2 — ссылка `tg://proxy`;
    *   **Сайт в Tor** — onion v3-адрес + статический сайт.
*   **Панель режим-aware:** в режиме 2 все операции с клиентами (создание, удаление, конфиги, LAN, рестарт, протоколы) прозрачно выполняются на SERVER-B; вкладка «Серверы» доступна только в каскаде; в заголовке отображается текущий режим.
*   **Бэкап под каждый режим:** режим 1 — локально на A; режим 2 — на B с копией на A; режим 3 — на A с копией на B.

Наследовано из v2: IPv6 в туннеле (ULA + NAT66), Telegram-уведомления из панели, Fail2Ban на обоих серверах, Stealth-режим (панель за сайтом-заглушкой на домене), переключение SERVER-B из браузера, отказоустойчивая установка через зеркала.

## 🏗 Архитектура режимов

**Режим 1 — один сервер:**
```text
┌────────┐      ┌─────────────────┐      ┌──────────┐
│ Client │ ───► │  SERVER-A       │ ───► │ Internet │
│ (Amnz) │ UDP  │  awg1 + панель  │ NAT  │          │
└────────┘ :585 └─────────────────┘      └──────────┘
```

**Режим 2 — панель на A, протоколы на B:**
```text
┌────────┐      ┌──────────────────┐      ┌──────────┐
│ Client │ ───► │  SERVER-B        │ ───► │ Internet │
│ (Amnz) │ UDP  │  awg1 + клиенты  │ NAT  │          │
└────────┘ :585 └──────────────────┘      └──────────┘
                        ▲ SSH-ключ (управление)
                ┌───────┴──────────┐
                │  SERVER-A        │
                │  только панель   │
                └──────────────────┘
```

**Режим 3 — каскад (максимальная скрытность B):**
```text
┌────────┐      ┌─────────────────┐      ┌──────────────────┐      ┌──────────┐
│ Client │ ───► │  SERVER-A (RU)  │ ───► │  SERVER-B (DE)   │ ───► │ Internet │
│ (Amnz) │      │  Web-Panel      │      │  (Выходной узел) │      │          │
└────────┘ UDP  │  awg1 → awg0    │ UDP  │  awg0 → NAT      │      └──────────┘
          :585  └─────────────────┘ :8443└──────────────────┘
```

## 🚀 Установка (Быстрый старт)

На чистом сервере (всегда на **SERVER-A**, от `root`, Ubuntu 22.04 / Debian 12):

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/deploy.sh -o /tmp/deploy.sh >/dev/null; cat /tmp/deploy.sh)"
```

Скрипт интерактивно запросит:
1. **Режим установки** (1 — только A, 2 — только B, 3 — каскад; по умолчанию 3).
2. IP-адреса серверов и SSH-пароль SERVER-B (режимы 2 и 3; используется единоразово).
3. Домен для Endpoint в клиентских конфигах (Enter = IP).
4. Разрешение на установку Web-панели и Fail2Ban.
5. Если на выходном узле есть IPv6 — предложит включить IPv6.
6. Если Endpoint — домен (режимы 1/3) — предложит сразу спрятать панель в Stealth-режим.

Все общие параметры установки (режим, подсети, порты, MTU, флаг IPv6, адрес SERVER-B) сохраняются в `/etc/amnezia-cascade.env`.

После установки веб-панель доступна по `https://<IP SERVER-A>:8000` — или сразу за доменом, если включён Stealth-режим.

## 🧩 Дополнительные протоколы (вкладка «Протоколы»)

Из веб-панели (вкладка «🧩 Протоколы») устанавливаются на сервер с протоколами (A в режимах 1/3, B в режиме 2):

| Протокол | Порт по умолчанию | Ссылка для клиента |
|---|---|---|
| VLESS + REALITY (Xray) | 443/tcp | `vless://...` (импорт в AmneziaVPN) |
| MTProxy (Telegram, mtg v2) | 8444/tcp | `tg://proxy?...` |
| Сайт в Tor | onion v3 | `http://xxxx.onion` |

То же самое из консоли сервера с протоколами:
```bash
sudo amnezia-proto-xray-vless.sh install   # install | remove | status
sudo amnezia-proto-mtproxy.sh install
sudo amnezia-proto-tor-site.sh install
```
Необязательные параметры передаются через окружение: `XRAY_PORT`, `XRAY_SNI`, `MTG_PORT`, `MTG_DOMAIN`, `ENDPOINT_HOST`.

## 🛡️ Защита веб-панели (Stealth-режим)

Панель прячется за сайтом-заглушкой (Nginx) на вашем домене: по IP и по корню домена открывается нейтральная страница, панель — только по секретному пути `https://домен/кодовое_слово/`. SSL выпускается через Let's Encrypt автоматически.

* **При установке:** если Endpoint — домен, установщик предложит включить Stealth сразу и спросит кодовое слово.
* **Позже:** `sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/stealth-setup.sh)"` или `deploy.sh --update`.
* **Свой сайт:** залейте свой `index.html` в `/var/www/stealth` — перенастройка не потребуется.
* **Аварийный доступ:** `sudo amnezia-panel-access.sh on|off` — временно открыть/закрыть панель по IP:8000.

В режиме 2 домен Endpoint указывает на SERVER-B, поэтому Stealth для панели на SERVER-A настраивается отдельным доменом через `--update`.

## 🔄 Обновление компонентов

Обновляет скрипты и панель, не трогая конфиги, клиентов и SERVER-B:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/deploy.sh)" -- --update
```

Панель сама проверяет наличие новых коммитов в этом репозитории (кнопка «🔄 Обновления»).

## 💾 Бэкап и восстановление

Бэкап (ключи, конфиги awg, клиенты, настройки панели и stealth) — ежедневно по cron + сразу после установки, хранятся последние 7 копий. Вручную: `sudo amnezia-backup.sh`.

* **Режим 1:** копии в `/root/amnezia-backups` на SERVER-A.
* **Режим 2:** бэкап делается на SERVER-B, копия прилетает на SERVER-A (SSH-ключ B→A).
* **Режим 3:** копии на SERVER-A + зеркало на SERVER-B (SSH-ключ A→B).

### Заблокировали SERVER-A (режим 3)

На новом сервере:
```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/deploy.sh)" -- --restore
```
Скрипт заберёт последний бэкап с живого SERVER-B и поднимет всё сам. Конфиги клиентов менять не нужно; если Endpoint — домен, обновите его A-запись.

### Заблокировали SERVER-B (режим 3)

* **Через веб-панель:** вкладка «Серверы» → добавить сервер → «Переключить».
* **Через консоль:** `sudo amnezia-restore-b.sh`

> В режимах 1 и 2 `--restore` и переключение выходного шлюза не применимы (нет каскадного туннеля) — восстановление делается переустановкой с последующим бэкапом из сохранённой копии.

## ⚙️ Управление через CLI (Консоль)

Все helper-скрипты ставятся на сервер с протоколами (в режиме 2 — на SERVER-B):

* **Добавление клиента:** `sudo amnezia-add-client.sh <имя>`
* **Удаление клиента:** `sudo amnezia-remove-client.sh <имя>`
* **Список клиентов и статистика:** `sudo amnezia-list-clients.sh`
* **Healthcheck туннеля:** `sudo amnezia-healthcheck.sh`
* **Настройка уведомлений Telegram:** `sudo amnezia-notify-setup.sh` *(или вкладка «🔔 Уведомления» в панели)*
* **Бэкап вручную:** `sudo amnezia-backup.sh`
* **Переключение SERVER-B (режим 3):** `sudo amnezia-restore-b.sh`
* **Дополнительные протоколы:** `sudo amnezia-proto-<имя>.sh install|remove|status`

## 📱 Клиентские приложения

* **AmneziaVPN** (рекомендуется) — импорт `.conf` и `vpn://`, также принимает ссылки `vless://`.
* **AmneziaWG** — классические `.conf` файлы.
* Для MTProxy — любой клиент Telegram по ссылке `tg://proxy` / `t.me/proxy`.
* Для сайта в Tor — Tor Browser.

> Стандартный WireGuard-клиент **не сможет** подключиться к AmneziaWG-интерфейсам (нет параметров обфускации Jc, S1, H1…).

## 🐛 Диагностика и FAQ

**Панель не запускается или недоступна:**
```bash
sudo systemctl status amnezia-panel
sudo journalctl -u amnezia-panel -n 30
```

**Режим 2: панель показывает ошибки доступа к клиентам** — проверьте SSH-ключ с SERVER-A на SERVER-B:
```bash
ssh -i /root/.ssh/id_ed25519 -o BatchMode=yes root@<IP-B> echo OK
```

**Клиент подключается, но интернета нет (режим 3):** проверьте туннель `ping -c 3 10.10.10.1` с SERVER-A.

**Низкая скорость / зависания:** MTU клиента 1280 или ниже; MSS Clamping уже прописан установщиком.

**Ограничения режима 2:** история трафика (sqlite) хранится на SERVER-B — панель показывает live-счётчики из `awg show`; Stealth настраивается отдельным доменом через `--update`.
